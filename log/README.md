# Change log

Narrative records of non-trivial changes to FAME: what changed, why, and what was
verified. One file per change, named by date.

These are written for a person reading months later who needs to know why the code
looks the way it does. They explain reasoning that a git diff cannot: which
alternatives were rejected, what was deliberately left alone, and what was tested
versus assumed.
